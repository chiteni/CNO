CNO HTML Lab

This standalone website contains an HTML editor and a protected live preview. The code box is for HTML; scripts inside the preview are disabled. A small script in the page itself powers Run, preview, and line numbers.

Windows: open a terminal in this folder and run `py -m http.server 8000`, then open http://localhost:8000.
macOS/Linux: run `python3 -m http.server 8000`, then open http://localhost:8000.
