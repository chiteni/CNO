CNO JavaScript Lab

This is a static website with no installation or dependencies.

To run it on Windows, open this folder in a terminal and run:
  py -m http.server 8000
Then visit http://localhost:8000 in your browser.

On macOS or Linux, run:
  python3 -m http.server 8000
Then visit http://localhost:8000.

The editor accepts JavaScript. Click Run or press Ctrl+Enter to see output in the console.
